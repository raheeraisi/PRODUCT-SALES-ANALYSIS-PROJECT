Product Sales Analysis Dashboard | Power BI
Project Overview
The Product Sales Analysis Dashboard is an interactive business intelligence project developed using Microsoft Power BI to analyze product sales performance, customer purchasing patterns, regional sales, payment methods, and sales trends over time.
The project transforms raw sales data into meaningful business insights through data preprocessing, data modeling, DAX calculations, and interactive visualizations. It helps users monitor key performance indicators (KPIs), compare sales performance across periods, identify top-performing products and regions, and make data-driven business decisions.
Objectives
*Analyze overall sales performance and key business metrics.
*Identify top-performing products and product categories.
*Compare sales across different regions.
*Understand customer purchasing behavior.
*Analyze payment method preferences.
*Track monthly and yearly sales trends.
*Build an interactive dashboard using slicers, bookmarks, drill-through, and navigation features.

Tools and Technologies
*Microsoft Power BI Desktop — Dashboard development and visualization.
*Power Query — Data cleaning and preprocessing.
*DAX (Data Analysis Expressions) — Measures and business calculations.
*Data Modeling — Fact and dimension tables with relationships.
*Microsoft Excel — Data inspection and preprocessing.
Data Preparation and Modeling
The project includes the following data preparation and modeling steps:
*Cleaned and prepared the sales dataset.
*Organized the data into a fact table and dimension tables.
*Created dimension tables for Region, Product, and Payment.
*Added the required keys to connect the fact table with the dimension tables.
*Established relationships between tables to support accurate analysis.
*Created DAX measures for sales analysis and performance comparisons.

Dashboard Features
*KPI Cards: Display key sales performance indicators.
*Sales by Region: Compare sales performance across geographical regions.
*Product Analysis: Identify products and categories contributing to sales.
*Payment Analysis: Examine sales distribution by payment method.
*Monthly Sales Trend: Track changes in sales over time.
*Yearly Sales Comparison: Compare sales performance across years.
*Sales Tables: Present detailed monthly and order-level information.
*Interactive Slicers: Filter dashboard results according to available business dimensions.
*Bookmarks and Navigation: Navigate between report pages and saved dashboard views.
*Drill-Through and Drill-Down: Explore detailed information from summary-level visuals.
*Gauge and Funnel Charts: Present target-related performance and stage-based analysis where applicable.
*Hyperlinks: Provide navigation to relevant source file.
