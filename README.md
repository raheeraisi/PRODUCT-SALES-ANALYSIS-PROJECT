#Product Sales Analysis Dashboard | Power BI  

#Project Overview  

  The Product Sales Analysis Dashboard is an interactive business intelligence project developed using Microsoft Power BI to analyze product sales performance, customer purchasing patterns, regional sales, payment methods, and sales trends over time.
The project transforms raw sales data into meaningful business insights through data preprocessing, data modeling, DAX calculations, and interactive visualizations. It helps users monitor key performance indicators (KPIs), compare sales performance across periods, identify top-performing products and regions, and make data-driven business decisions.  

#Problem Definition  

Businesses generate sales data across different products, regions, payment methods, and time periods. However, analysing this data using raw transaction records can make it difficult to identify sales trends, compare performance across periods, and understand patterns in customer orders and product sales.  

 
#Objectives  

The objective of this project is to transform raw product sales data into an interactive Power BI dashboard that presents meaningful sales insights.

*Analyze overall sales performance and key business metrics.  

*Identify top-performing products and product categories.  

*Compare sales across different regions.  

*Understand customer purchasing behavior.  

*Analyze payment method preferences.  

*Track monthly and yearly sales trends.  

*Build an interactive dashboard using slicers, bookmarks, drill-through, and navigation features.

#Tools and Technologies  

*Microsoft Power BI Desktop — Dashboard development and visualization.  

*Power Query — Data cleaning and preprocessing.  

*DAX (Data Analysis Expressions) — Measures and business calculations.

#Data Preparation and Modeling    
#Dataset Source  

Dataset name: Product Sales by Region  

Source file: Product-Sales-Region.xlsx  

Source website: Excelx.com – Sample Sales Data  

Format: Microsoft Excel (.xlsx)  

Purpose: Product sales analysis and interactive business intelligence reporting. 

#Dataset Overview  

The dataset contains sales transaction information used to analyse product performance, regional sales, quantities sold, discounts, payment methods, and order-related patterns. The source website describes the dataset as containing 1,500 rows across multiple regions and store locations.  

#Main Data Fields  

*Date	-Date associated with the sales record  

*Region-	Geographic sales region  

*Product-	Product sold  

*Quantity-	Number of units sold  

*UnitPrice-	Price per unit  

*TotalPrice	-Total sales amount  

*Discount-	Discount applied to the sale  

*PaymentMethod-	Method used to pay for the purchase  

*Promotion-	Promotion associated with the transaction  

*Returned	-Indicates whether a product was returned  

*CustomerName-	Customer name recorded in the source data  

*ShippingCost-	Cost of shipping  

*OrderID-	Order identifier  

*StoreLocation-	Location of the store  
#Data Modelling
The data was organised in Power BI using a central sales fact table and three dimension tables:  

Region Dimension: Supports geographic analysis.  

Product Dimension: Supports product-level analysis.  

Payment Dimension: Supports payment-method analysis.  

Relationships between the dimension tables and the fact table enable consistent filtering and aggregation in the dashboard.
#Data Analysis  

The dataset supports the following analyses:  

Sales performance by region and product.  

Monthly sales trends  comparisons.  

Quantity and revenue analysis  

Payment-method patterns.  

Order-level filtering and exploration.  

Interactive reporting using KPIs, charts, slicers, and navigation features.  

#Dashboard Features  

*KPI Cards: Display key sales performance indicators.  

*Sales by Region: Compare sales performance across geographical regions.  

*Product Analysis: Identify products and categories contributing to sales.  

*Payment Analysis: Examine sales distribution by payment method.  

*Monthly Sales Trend: Track changes in sales over time.  

*Yearly Sales Comparison: Compare sales performance across years.  

*Sales Tables: Present detailed monthly and order-level information.  

*Interactive Slicers: Filter dashboard results according to available business dimensions.  

*Bookmarks and Navigation: Navigate between report pages and saved dashboard views.  

*Drill-Through and Drill-Down: Explore detailed information from summary-level visuals.  

*Gauge and Funnel Charts: Present target-related performance and stage-based analysis where applicable.  

*Hyperlinks: Provide navigation to relevant source file.
